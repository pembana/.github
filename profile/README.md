# Pembana™ 🌿

**Software for living plant collections—and the open-source tools behind it.**

Pembana™ brings together botanical collection management, environmental data, and reusable software libraries. We build modern software for botanical gardens, arboreta, and serious plant collectors. Along the way, we give back to the open-source community by publishing libraries and tools that we develop and maintain for our own applications under permissive licenses.

## Open-source projects

| Project | What it does |
| --- | --- |
| [Pembana Search](https://github.com/pembana/pembana-search) | Advanced search expressions for [Spring Data JPA](https://spring.io/projects/spring-data-jpa), with optional [Spring Boot](https://spring.io/projects/spring-boot) and [Spring MVC](https://spring.io/projects/spring-framework) integration. |
| [Pembana Image Filters](https://github.com/pembana/pembana-image-filters) | Java image-processing filters based on Jerry Huxtable’s JHLabs filters. |
| [Pembana Rain Gauge](https://github.com/pembana/pembana-rain-gauge) | Explore recent and historical rainfall observations from Hawaiʻi monitoring stations, with clear reporting of data gaps and quality issues. |

These projects can be used independently of Pembana. Each repository includes its documentation, development status, and license information.

## Get involved

Bug reports, feature suggestions, documentation improvements, and code contributions are welcome. Visit the relevant repository to open an issue or read its contribution guidelines.

If you work with living plant collections, we also welcome ideas about the workflows and data challenges that matter to you.

Learn more at [pembana.com](https://www.pembana.com/).
